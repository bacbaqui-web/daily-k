## 선별

- 애객(aagag.com)의 공개 이슈 목록과 본문만 확인합니다. 다른 커뮤니티와 SNS를 별도로 탐색하지 않습니다. 애객이 제공한 원본 링크는 출처로 표시합니다. 접근 제한 또는 CAPTCHA가 나오면 우회하거나 다른 플랫폼으로 대체하지 않고, 본문 수집 실패와 사용자 인증 필요를 보고합니다.
- 현재 한국시간에 맞는 회차: 09~20시 am, 21시 이후 pm, 00~08시 지연 실행은 전날 pm. cutoffAt은 09:00/21:00 KST로 고정하며 generatedAt은 실제 생성 시각입니다.
- 회차 기준 최근 24시간 글 위주로 후보 30~50개를 조사하고 15~20개를 고릅니다. 검증 가능한 글이 적으면 실제 확인한 개수만 발행하고 목표에 못 미친 이유를 알립니다. 최소 3개. 3개 미만이면 만들지 말고 실패 보고합니다.
- 화제·유머·정보가 균형 있게 섞이도록 선정합니다. 베스트 등재, 댓글·추천·조회 수, 여러 커뮤니티 재등장 등 실제 확인한 인기 근거를 남깁니다. 검색 결과 노출만으로 인기라고 단정하지 않습니다. 수치를 추측하지 않습니다.
- 본문과 실제 게시 시각을 확인합니다. 사실 주장은 가능하면 공식 출처로 검증하고, 경험담·유머·미확인 주장을 명확하게 구분합니다. 개인정보 노출·성인물·악의적 루머·광고는 제외합니다.
- 이전 14개 회차의 topicKey와 원문 URL을 비교해 중복 제거합니다. 동일 글의 다른 커뮤니티 재게시도 하나의 항목으로 묶습니다.

```json
{"schemaVersion":1,"timezone":"Asia/Seoul","id":"YYYY-MM-DD-am","date":"YYYY-MM-DD","edition":"am","cutoffAt":"YYYY-MM-DDT09:00:00+09:00","generatedAt":"실제 ISO 시각","overview":["인터넷 화제 요약"],"stories":[{"id":"안정된 짧은 ID","topicKey":"중복 판별 키","title":"제목","category":"화제","summary":["짧은 요약","배경과 핵심 내용"],"selectionReason":"고른 이유","popularityEvidence":"실제 확인한 인기 근거","verificationNote":"사실 확인 수준 또는 경험담/유머 구분","imageUrl":null,"sources":[{"name":"커뮤니티 이름","title":"실제 원문 제목","url":"실제 원문 URL","imageUrl":null,"publishedAt":null,"verifiedAt":"실제 확인 시각"}]}]}
```

게시 시각 미확인은 null로 남기고 verificationNote에 한계를 밝힙니다. null을 최신 글 확인 대용으로 사용하지 않습니다. 날짜가 불분명한 과거 글은 선정하지 않습니다.

## 영상과 출처 그래프

선정한 애객 본문에 영상이 있으면 실제 video src와 poster의 공개 URL을 각각 videoUrl, videoPosterUrl에 저장합니다. 페이지 안에서 재생 버튼이 있는 영상으로 보여 주며 자동 재생하거나 영상 파일을 다운로드하지 않습니다. 영상 URL이 없으면 다른 글의 영상을 대신 넣지 않습니다.

본문의 출처 보기를 펼쳐 커뮤니티별 재게시 항목을 세고 sourceBreakdown에 [{"name":"루리웹","count":2},{"name":"펨코","count":1}] 형태로 저장합니다. 같은 커뮤니티는 합산하고 실제 확인 시각 sourceStatsVerifiedAt을 ISO 형식으로 남깁니다. 한 줄 누적 막대에 커뮤니티 이름과 횟수를 표시합니다. 당일 추천/댓글/조회수나 순위로 오해하지 않도록 누적 출처로 표기합니다. 세부 집계를 못 확인하면 필드를 생략하고 미확인으로 표시합니다. 총합만 보고 커뮤니티별 숫자를 추정하지 않습니다. 선정 이유와 확인 범위는 원본 링크 아래에서 기본으로 접힌 영역을 눌러 확인합니다.
