# 주요 뉴스 편집과 발행
## 편집 기준
1. 분야별 수량 할당 없이 중요한 뉴스를 먼저 선정합니다. 영향 범위, 실제 변화와 생활 영향을 비교합니다. 같은 분야 여러 기사와 분야 생략을 허용합니다.
2. 이전 대표·예비와 새 내용 없는 반복을 제외합니다. 새 사실이 확인된 후속만 차이와 근거를 적습니다.
3. 기사 본문과 출처를 확인하고 사실·주장·예정·불확실성을 구분합니다. URL, 수치, 시각은 추측하지 않습니다.

예비 기사와 분야별 최소·최대 수량을 요구하지 않습니다. 일정과 키워드도 선택 사항이며 개수를 채우기 위한 검색은 하지 않습니다. 설명은 독자가 사건과 중요성을 이해할 만큼 쓰고 기존 화면의 JSON 구조를 따릅니다.

## 발행 안전
회차 ID와 원래 09시/21시 KST cutoffAt을 유지합니다. 기준 이후 정보와 조작한 생성·검증 시각을 사용하지 않습니다.
기존 회차·operationId·원격 Git·실서비스·전송 영수증을 대조하고 중복 생성·덮어쓰기·중복 전송하지 않습니다.
기존 잠금과 트랜잭션 복구 경로를 사용합니다. 홈페이지 게시가 끝났다면 미완료 배달만 재개합니다.
실제 홈페이지 내용과 디스코드 영수증·메시지를 확인해야 완료입니다.
뉴스 외 서비스·예약을 변경하지 않습니다.
